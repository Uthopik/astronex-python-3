# Astro-Nex (Python 3 / GTK3)

Astronex es un programa de astrología para calcular y dibujar cartas de acuerdo al Método API. Usado en el método Huber. Versión Python 3.

## Installation

- En **Windows**, haga doble click en el archivo, y si le pide permiso, concédaselo.

- En **Linux**, haga click derecho en el archivo **AppImage** y concédale permiso en el apartado de **‘Permisos’.** También puede dar permiso por terminal con este comando:

```bash
chmod +x ./Astro-Nex-Dark-v2.1.AppImage
```

- En distribuciones **basadas en Debian** como **(Ubuntu, Linux Mint,...)**, puede instalarlo con el archivo **.deb.** Abra la terminal en la ubicación del archivo y use este comando:

```bash
sudo apt install ./astro-nex-dark-v2.1.deb
```

- En distribuciones **basadas en Arch** como **(Cachy, Manjaro, Endeavour,...)** se puede instalar vía **AUR**:

```bash
sudo pacman -S --needed base-devel yay
yay -S astronex
```
